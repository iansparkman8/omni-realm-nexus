# Trek & Tally

An offline trail log for long-distance hikers: miles, weather, calories, boot wear, camps, a pack list, and a CSV export. No account, no server, no tracking; data stays in the browser (IndexedDB).

Plain HTML/CSS/JS, no build step. Deploy by serving this folder over HTTPS (GitHub Pages works); the service worker then caches the app for offline use.

Built by Claude with Gemini (spec) and Grok (art) for Ian Sparkman. Status: v0.1, UNVERIFIED on real devices.
